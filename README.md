- **AI security:** threat modeling against OWASP Top 10 for LLM and MITRE ATLAS, prompt injection defense, LLM red teaming, model cards and guardrail configuration
- **Zero Trust:** Cloudflare Zero Trust tunnels, Teleport privileged access with just-in-time grants, Keycloak SSO and RBAC
- **Detection engineering:** Falco eBPF runtime detection, 17 Sigma rules, Datadog monitors and dashboards, SOAR playbooks in n8n
- **DevSecOps:** Trivy, Semgrep, Gitleaks, OPA/Rego policy gates, Cosign image signing, SBOM generation, OIDC-federated CI with no stored cloud keys
- **Infrastructure as code:** Terraform for Oracle Cloud and Cloudflare with remote locked state, nightly drift detection, 8 OPA policies, and the AWS generation kept in the repo
- **GRC:** 57 documents: System Security Plan mapped to NIST 800-53, POA&M, 10 policies, 5 incident response playbooks, 6 threat modeling documents, AI governance policy and AI incident playbook, HIPAA, SOC 2, and ISO 27001 crosswalks
